01 / OVERVIEW

CSVの集計・検証・出力を行う自主制作ツール。Python版とGAS版のコードを収録。

表示されるビジュアルと数値は説明用のイメージです。過去の実案件の納品物や運用実績ではありません。

02 / IMPLEMENTATION

  • 注文データのCSV取込、金額の集計、入金状況別の分類
  • 注文IDの重複チェックや不正金額の検出
  • 集計結果のCSV出力。Python版はサンプルテスト済み
  • GAS版はスプレッドシート環境での動作検証が必要

03 / APPLICATIONS

  • Excel・CSV処理の自動化
  • 売上・請求・在庫データの集計
  • Googleスプレッドシートの反復処理
